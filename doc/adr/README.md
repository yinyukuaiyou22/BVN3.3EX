# ADRs (Architecture Decision Records)

按 [mattpocock/skills `domain-modeling` 的 ADR-FORMAT](https://github.com/mattpocock/skills/blob/main/skills/engineering/domain-modeling/ADR-FORMAT.md) 规范维护.

## 命名

`<NNNN>-<slug>.md` (NNNN = 4 位递增序号，从 `0001` 开始)

## 模板

```md
# {Short title of the decision}

{1-3 sentences: what's the context, what did we decide, and why.}
```

最小可工作 ADR 可只一段。当所有以下条件都成立时才写 ADR:

1. **Hard to reverse** — 改主意成本高
2. **Surprising without context** — 未来读者会问"为什么要这样"
3. **The result of a real trade-off** — 真的有多个备选并做了权衡
