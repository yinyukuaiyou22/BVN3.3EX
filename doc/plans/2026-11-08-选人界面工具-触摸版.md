# 选人界面排版工具 · 单文件触摸版（2026-11-08）

> 交付：**就地升级** [`选人界面排版工具/select-layout-tool.html`](../../选人界面排版工具/select-layout-tool.html)（单文件、无外链、无构建）。
> 桌面鼠标 / 滚轮 / 键盘行为逐项保留；触摸设备自动切到触摸 UI（`?ui=touch|desktop` 可强制，面板内可切换并记忆）。

## 目标

1. **功能完全**：桌面 15 项能力在触摸下全部有入口（对照表见 §4），不删功能、不简化语义。
2. 手机竖屏（390×844）、横屏（844×390）、平板（768×1024）都不横向溢出、控件不被裁、可点控件 ≥44×44 CSS px。
3. 手势：点选 / 拖动格子 / 空白拖动平移 / 双指捏合缩放（0.5–3×）/ 双指拖动平移；「参考图·调整」下拖动=移背景、双指=缩背景。
4. 只有 offset 真变化才 `markDirty()`；**一次手势 = 一步撤销**；双指手势绝不改 offset。
5. 导出文本与桌面逐字节一致（`serializeXML` 未改）。
6. 旧 `verify-*.js` 10 个全绿；新增 `verify_browser.js`（真浏览器）全绿；桌面 1280×800 视觉不变。

## 1. 结论与关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 交付形态 | 就地升级同一文件 | 唯一事实源，避免解析/序列化/网格公式两份漂移；桌面路径用 `IS_TOUCH_UI` 分支隔离 |
| 缩放/平移 | **CSS 尺寸 + CSS transform**，位图按 DPR 提分辨率 | 绘制仍用 0..800 视口坐标，`mapToScreen/mapFromScreen/hitTest` 一行不改；桌面位图仍 800×600 |
| 平移存储 | 视口像素（0..800），屏幕位移 = pan × (fit×zoom) | 焦点缩放公式可纯函数化、可在 Node 里断言 |
| 手势库 | 原生 `TouchEvent`（无依赖） | 合成事件可在 headless Chrome 里真跑；`preventDefault` 能压掉兼容鼠标事件 |
| 视角归属 | 模块级 `view`，不进 `state` | 撤销不该回滚缩放/平移 |
| 全新按钮 | 只在触摸 UI 显示（`body.touch-ui`） | 桌面保持原样（Ctrl/Alt 点击、Delete 仍在） |

### 2.2 触摸手势层（3676–4000 附近）
`TOUCH` 状态机：`none | pending | drag | pan | pinch | bgDrag | bgPinch`。

- 阈值：`TAP_SLOP=8` 视口 px、`TAP_MS=500`、`LONG_PRESS_MS=450`。
- 单指：命中格子且未锁定 → drag（复用 `dragState`，手势开始 `pushUndoSnap()`）；空白 → pan；`refBg.edit` → bgDrag（复用原公式）。
- 双指：先 `commitDrag()`（不撤回已写入的 offset）再 pinch；`updatePinch()` = 中点位移 → 平移，距离比 → `zoomAtLocal(中点, 比)`。
- 抬起：位移 < slop 且 < 500ms → `handleTap()`（命中→选中；再点同一格→打开「格子」页）；`touchcancel` 同路径收尾。
- 长按：震动 + 选中 + 打开「格子」页（不改 offset）。
- 锁定（`#fab-lock`）：canvas 只允许点选/平移/缩放。

坐标映射（与鼠标同源）：`Δxml = Δ视口px / viewport.scale`；`Δ视口px = ΔCSS / (fit×zoom)`。

### 2.3 触摸 UI（CSS 约 380–560 行区间 + 新 DOM）
- 顶栏只留「标题 + 导入 + 导出 + 人物页/辅助页」；≤430px 时按钮去掉「XML」后缀、标题截断。
- 画布浮动：右上 `#touch-fabs`（↶ ↷ ⤢ 🔒，44×44）；左下 `#page-pill`（‹ 1/20 ›）；右下 `#btn-panel`（⚙ 开合面板）。
- 面板 = 原 `#sidebar` 复用：竖屏底部抽屉（tab 条 61px + 内容区，52dvh，可折叠）；横屏右侧 `min(40vw,320px)` 常驻。
- 8 个 tab：布局/网格/间距/参考/格子/页面/列表/日志（`#sheet-tabs` 桌面隐藏）。
- 触摸控件：`min-height:44px`、数字框 16px（防 iOS 聚焦缩放）、`@media (hover:none)` 去 hover 粘滞。
- 首次进入弹手势说明（`#touch-help`，记 localStorage）。

### 2.4 导入 / 导出 / 自动保存
- 导出：触摸 UI → 弹层（下载 / 复制 XML / 分享 / 只读预览）；桌面仍是直接下载（行为不变，`verify-dragdrop` 仍断言导出清脏）。
- 导入：触摸 UI → 弹层（选文件 或 粘贴 XML）；桌面仍走隐藏 file input。
- 自动保存：`localStorage['select-layout-tool:auto:v1']`，600ms 防抖 + `pagehide/visibilitychange`；只在 `dirty` 时提示「恢复 / 丢弃」，不自动覆盖。

## 3. 实施中钉死的 5 个坑（都写进了代码注释）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 进触摸 UI 后画布错位约 0.7s | `#canvas` 的 `canvasIn` CSS 动画会覆盖 inline `transform` | 触摸 UI 下 `animation:none` |
| 2 | 390 宽的手机上整页变成 439 宽 | `#app{width:100vw}`（含滚动条）+ 网格列 `1fr` 的 min-content = 顶栏不换行内容 | `width:100%` + `grid-template-columns:minmax(0,1fr)` + 子项 `min-width:0` + 触摸 UI 下 `html/body overflow:hidden` |
| 3 | tab 条被压成 20px、文字被裁 | `#sheet-tabs` 是 `overflow-x:auto` 的 flex 子项，scroll 容器 `min-height:auto`=0，被压缩 | `flex:0 0 auto` |
| 4 | 顶栏「导入 XML」折成两行、标题挤掉按钮 | 按钮默认 `flex-shrink:1` + `white-space:normal` | 按钮 `flex:0 0 auto; white-space:nowrap`，标题 `flex:1 1 0` |
| 5 | DPR 提分辨率后点选偏移 | `evtToCanvas` 用 `canvas.width`（=800×q）换算 | 改用视口基准 `VP_W/rect.width` |

## 6. 已知限制

- 手机格子初始约 28 CSS px（fit 0.475），**精调靠捏合放大**（放大后 1 CSS px ≈ 1/(fit·zoom) 布局单位）；未做「点小格弹出放大镜」。
- 参考图仍**会话级**：不写 XML、不进自动保存。
- 自动保存只在同一浏览器可用；iOS `file://` 可能禁用 localStorage 与下载，此时降级为「复制 XML」，建议改用局域网 `http` 打开。
- 横屏矮屏（<620px 高）面板常驻右侧，画布可视区较小（844×390 下约 428×321），这是取舍。
- 触摸 UI 的 44px 命中区按 CSS 像素算，不保证每台设备的物理手感。
