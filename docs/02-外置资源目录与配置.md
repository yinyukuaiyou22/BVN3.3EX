# 02 外置资源目录与配置

## 目录

    /storage/emulated/0/Android/media/air.com.bvn.yy798/BVN/assets/
      config    配置文件
      fighter   人物
      map       地图
      face      头像
      bgm       背景音乐
      sounds    音效

配置里写的路径都相对于这个根目录。写 assets/xxx 也会先到外置目录找，找不到才用安装包里的。

## 读资源的顺序

固定的四步，不会跳步：

1 绝对路径，直接读；
2 相对路径，先到外置目录找；
3 外置没有，读安装包内置；
4 全都没有，报错或者用默认值。

日志里 EXT-RESOLVE 后面写 external 就是读了外置，写 apk-fallback 就是回退到内置。排查时先看这一行。

## 配置文件

五个文件都放在 config 目录，格式是 xml。

fighter.xml 定义人物。每个 fighter 节点至少要写 id、name 和文件地址。id 是唯一标识，配置之间靠它互相引用。

select.xml 决定谁出现在选人界面。里面的 char_list 是一格一格的位置，每格一个 item，item 上的 fighterID 指向 fighter.xml 里的 id。没写进 char_list 的人物，即使 fighter.xml 里有，也不会出现在选人界面。

assist.xml 定义助战角色，字段和 fighter.xml 类似。

map.xml 定义地图和地图对应的背景音乐。

preload.xml 定义开局前要预加载的资源，写进去的会先加载，减少进战斗时的等待。

## 外置人物要同时满足三条

1 fighter.xml 里有对应的 fighter 节点；
2 对应的 swf 文件能读到；
3 select.xml 的 char_list 里有同名 item。

少任何一条都不会出现在选人界面，这是设计如此，不是 bug。缺 swf 时会直接跳过，不会报错。

## 同名怎么办

内置和外置有同一个人物 id 时，内置优先。想用自己的版本，把内置那个的 id 改掉，或者用外置的新 id。

## 地图

地图写进 map.xml，外置 swf 放 map 目录。地图的背景音乐也在 map.xml 里指定，文件放 bgm 目录。缺音乐不影响进地图，只是没有声音。
