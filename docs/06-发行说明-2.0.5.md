## 本次改动

一 手柄支持。设置菜单里新增手柄入口：主菜单 OPTION → GAME CFG → 第一行的「手柄设置」，点进去就是改键页。设备绑定、逐键录制、还原默认、应用都在这一页。

二 修复改键不生效。此前在改键页改完，战斗里生效但主菜单仍按旧键，表现为「改了没用」。现在菜单的键位表会跟随玩家一的手柄配置。

三 修复返回键与确认键冲突。此前按确认键会顺带触发返回，现在两键分开。

四 修复退出手柄设置后按键卡住。此前改键页退出后页面看不见了，但按键仍被它拦截；现在退出即销毁。

五 修复回到主菜单后按键全部无响应。

六 滤镜效果项从常规设置搬到画面设置（CAMERA CFG 里 QUALITY 下面），PC 端也会显示。

七 移除改键页里的「购买推荐手柄」按钮。

## 手柄怎么设

默认键位表是按真实 Xbox 无线手柄标定的：A 跳跃、B 冲刺、X 攻击、Y 技能、LB 召唤、RB 必杀、左摇杆卍解、十字键方向、Start 返回、Select 确认。

换别的手柄（其他品牌、有线老型号、模拟器造出来的虚拟手柄）时控件编号可能完全不同，需要自己录一遍：进改键页先按 SET DEFAULT 还原，再按 SET ALL 按提示逐键按下。录完回设置列表按 APPLY 保存。

注意改键页自己的 APPLY 只写进内存，真正落盘要在设置列表再按一次 APPLY。
