# 03 人物子框写法与触发

## 什么是人物子框

选人界面里，一个格子上可以挂多个角色。长按这格，其余角色会按八个方向环绕展开成一个小框，点其中一个就选中它。一个格子挂几个，格子上就显示几的角标。

这个机制叫人物子框。它只对配了 plugin 的角色生效，没配的角色长按没有反应，这是设计如此。

## 怎么写

两个地方都可以写，按需要选一个，不要两边都写。

第一处，fighter.xml 的 fighter 节点加 plugins 属性，值是角色 id，逗号分隔：

    <fighter id="灵梦" name="博丽灵梦" file="fighter/灵梦.swf" plugins="妹红,魔理沙"/>

第二处，select.xml 的 char_list 里那一格的 item 加 plugins，只影响这一格：

    <item fighterID="灵梦" x="0" y="0" plugins="妹红,魔理沙"/>

写在 fighter.xml 里，这个角色在所有出现的地方都带子框；写在 select.xml 的格子里，只有这一格带。两处都写时以 select.xml 那一格为准。

## 子角色也要完整

plugins 里写的每一个 id，都必须自己满足三条：fighter.xml 有节点、swf 能读到、在 select.xml 里不用单独占格子（子框会自动建）。

不满足的会被跳过，格子照样展开，但那个位置是空的。

## 触发方式

选人界面长按格子。手机是按住不放，PC 是按住鼠标左键。

展开后子角色按八个方位环绕，点其中一个即可选中，再点同一格确认进入。

## 数量

一个格子最多放八个，多出来的不会显示。角标显示的是实际配了几个。

## 示例

三个形态，主角色是灵梦，另外两个是她的变化：

    fighter.xml
    <fighter id="灵梦"   name="博丽灵梦"   file="fighter/灵梦.swf"   plugins="妹红,魔理沙"/>
    <fighter id="妹红"   name="藤原妹红"   file="fighter/妹红.swf"/>
    <fighter id="魔理沙" name="雾雨魔理沙" file="fighter/魔理沙.swf"/>

只要灵梦这一格配了 plugins，长按它就会展开三个。
