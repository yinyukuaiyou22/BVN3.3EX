# 01 安装与发布说明

## 装什么

安装包的名字是 air.BVNEXyinyu，桌面显示名是「死神vs火影」。装好之后直接打开就能玩，第一次启动会自动在手机里建好放资源的目录。

这个包名与 2.0.5 之前的旧包（air.com.bvn.yy798）是两个独立应用：可以同时装在一台手机上，互不覆盖，存档也不互通。换包之后进游戏会是一份全新的设置与存档。

安装包只带主程序、配置和启动必需的基础资源。人物、地图、音乐这类大件放在外置目录，可以自己加、自己换，不用重装。

## 第一次启动会做什么

游戏会在这个位置建目录：

    /storage/emulated/0/Android/media/air.BVNEXyinyu/BVN/assets/

并自动建好五个子目录：fighter、map、face、bgm、config。建不出来的时候日志里会写 External dirs FAILED，通常是这个位置被系统限制，换一台机器或者手动建一次即可。

## 怎么加资源

把文件按格式放进对应子目录，重启游戏就生效。不需要重装，也不需要重新打包。

    fighter  人物 swf 文件
    map      地图 swf 文件
    face     头像图片
    bgm      背景音乐
    sounds   音效
    config   五个配置文件

## 发行版的两种形态

完整版：资源都在安装包里，装上就能玩全部内容。

无资源版：安装包里只留主程序、配置和启动必需的基础资源，其余内容从外置目录读。适合自己整理资源的人，安装包小，替换资源不用重装。

两种版本玩法完全一样，区别只在资源放在哪。

## 中文文件名

用 adb 直接推中文名文件会被截断，例如 七夜.swf 会变成 七夜.。正确做法是先打包再解包：

    tar cf res.tar 七夜.swf
    adb push res.tar /sdcard/
    adb shell "cd /sdcard && tar xf res.tar"

或者直接用手机上的文件管理器拷贝，不受这个限制。

## 更新

换人物、换地图：替换外置目录里的文件，重启游戏。

换主程序：装新的安装包。外置目录里的资源不会被覆盖。
