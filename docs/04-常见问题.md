# 04 常见问题

## 人物装了但选人界面看不到

按顺序查这三条，缺一条就不显示：

1 fighter.xml 里有没有这个人的 fighter 节点，id 是否唯一；
2 对应的 swf 文件能不能读到，路径和大小写是否一致；
3 select.xml 的 char_list 里有没有 fighterID 相同的 item。

三条都在还看不到，看日志里有没有 EXT-RESOLVE 这一行。写 external 说明读到外置了，写 apk-fallback 说明读的是安装包里的旧文件。

## 地图装了但没出现

先看 map.xml 里有没有这个地图的条目，再看 swf 是否放进 map 目录。地图名和文件名要一致。

## 打开就黑屏或者提示创建游戏失败

多数是配置文件被改坏了。把外置 config 目录里的 xml 先改名移走，让游戏用安装包里的配置启动，能进说明是配置的问题，再逐个加回来定位。

日志里如果有 External dirs FAILED，是外置目录位置不对，确认路径是 Android/media 下的包名目录，不是 Android/data。

## 日志在哪看

文件日志在这个位置：

    /data/user/0/air.BVNEXyinyu/com.bvn.yy798/Local Store/bvn_debug.log

导出命令：

    adb exec-out run-as air.BVNEXyinyu cat "/data/user/0/air.BVNEXyinyu/com.bvn.yy798/Local Store/bvn_debug.log"

日志里经常要看的几个标记：EXT-RESOLVE 资源命中来源，SelectedUI setFighter 角色进了选人列表，GameLoader External dirs FAILED 外置目录建不出来。

## 中文文件名传上去变成半截

adb 直接推中文名会截断，用 tar 打包再解包，或者用手机文件管理器拷贝。

## 改了资源没生效

游戏启动时才扫描外置目录，改完要完全退出再进。只退到主菜单不算。
