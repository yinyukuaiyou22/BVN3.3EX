# 发行说明 2026-11-18

## 这个包是什么

无资源发行版。安装包里只有主程序、配置文件、基础音效与特效，人物、地图、头像、背景音乐全部从外置目录读取。

    bvn.apk
    大小 48.3 MB
    SHA256 1E89F4A696865CAC6A78EB008E140AED3BC3DD9520E9B2F696CEA1FFB99C58E2

装好后把资源放到这个目录，游戏启动时会自动扫描：

    /storage/emulated/0/Android/media/air.com.bvn.yy798/BVN/assets/

子目录：config、fighter、map、face、bgm、sounds。外置有就用外置，没有才回退到安装包内置。详细说明见 docs/02-外置资源目录与配置.md。

## 本次改动

一 镜头设置页。设置菜单新增 CAMERA CFG（主菜单 OPTION 下面第三项），进去可以一键切换原版与增强镜头，单独控制镜头距离、自动缩放、镜头震动，画质选项也搬到这一页。

二 镜头增强移植。从 3.7 参考搬入四块能力：距离四档、按包围盒自动缩放、留白钳制、震屏与缩放缓动。默认全部关闭，关闭时与改动前完全一致。

三 用户文档。新增 docs 目录，四个章节：安装与发布、外置资源与配置、人物子框写法与触发、常见问题。README 重写，重点说明资源可以放在外置目录、不必打进安装包。

## 已知事项

镜头增强部分只做了编译验证，没有逐项在真机上跑过。默认全部关闭时行为与旧版一致，可以正常游玩；要试增强功能，进 CAMERA CFG 打开总开关后再进战斗观察。

外置目录位置必须是 Android/media 下的包名目录，不能放 Android/data，后者普通应用建不出来。
